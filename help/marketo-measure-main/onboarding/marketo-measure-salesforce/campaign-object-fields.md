# 行銷活動物件欄位

本課程涵蓋[!DNL Marketo Measure]用來將行銷活動和行銷活動成員對應至行銷管道的Salesforce CRM Campaign物件欄位。 瞭解這些行銷活動物件的功用很重要，因為您必須在[!DNL Marketo Measure]中管理和對應您的離線頻道。
